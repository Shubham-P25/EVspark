# Raw Datasets (`data/raw/`)

This directory is git-ignored and intended for raw dataset files required by EVspark seed and training scripts.

## Required Datasets (Phase 5)

### 1. Ministry of Power Station Dataset (Mandatory for production seed)
- **Filename**: `data/raw/mop_stations.csv`
- **Source**: Ministry of Power / Dataful (ID 23369)
- **Description**: All-India EV charging station dataset.
- **Expected Columns / Headers**: Name, Operator/Network, State, District, City, Address, Latitude, Longitude.
- **Used by**: `scripts/seed/import-stations.ts`

### 2. Historical Demand / Session Datasets (Optional for training / profile refinement)
- **Filenames**:
  - `data/raw/acn_data.csv` (ACN-Data EV charging sessions)
  - `data/raw/dundee.csv` (Dundee EV charging sessions)
  - `data/raw/urbanev.csv` (UrbanEV dataset)
- **Used by**: `scripts/seed/build-patterns.ts` to compute hourly arrival profiles and session durations. If omitted, the engine uses the verified synthetic default profile in `data/patterns/hourly-profile.json`.

### 3. Open Charge Map Cache
- **Filename**: `data/raw/ocm-cache.json`
- **Generated by**: `scripts/seed/enrich-ocm.ts` if `OCM_API_KEY` is provided.
